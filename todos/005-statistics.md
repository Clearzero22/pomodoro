# 005 · 今日/本周统计 + 历史记录

- **状态**: ⬜ 待开始
- **优先级**: P1
- **分支**: `feat/005-statistics`
- **依赖**: 003 (持久化)

## 目标

让用户看到自己的专注积累。

## 需求

1. 今日已完成、专注总时长、连续天数
2. 本周柱状图（7天）
3. 历史记录列表（日期、完成数、专注时长）
4. 数据按天聚合，存储最近 90 天

## 设计要点

- 数据模型：`DailyRecord { date: String, completed: u32, focus_minutes: u32 }`
- 存储：复用 003 的持久化，`pomodoro:history` 单独 key
- UI：`gpui_kit` 的 `Chart` 或自绘 `div` 柱状图，复用 `ProgressCircle` 风格
- 统计视图作为第二页签，与计时器并列

## 任务拆解

- [ ] 1. `HistoryStore` 数据结构 + 按天聚合
- [ ] 2. 每次 `PhaseCompleted(Focus)` 时写入今日记录
- [ ] 3. 统计页 UI (今日卡片 + 周视图)
- [ ] 4. 历史列表 + 清空历史
- [ ] 5. 跨天自动归零逻辑

## 验收

- [ ] 完成 1 个番茄后今日计数 +1
- [ ] 跨天后自动新建一天记录
- [ ] 周视图正确显示 7 天数据
