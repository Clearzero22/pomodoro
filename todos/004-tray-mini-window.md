# 004 · 托盘 + 迷你窗 + 全局快捷键

- **状态**: ⬜ 待开始
- **优先级**: P1
- **分支**: `feat/004-tray-mini-window`
- **依赖**: 001

## 目标

桌面端常驻托盘，迷你窗悬浮显示，支持全局快捷键控制。

## 需求

1. 系统托盘：图标随阶段变色，菜单含 开始/暂停/重置/显示主窗口/退出
2. 迷你窗：60x60 圆形悬浮窗，只显示剩余时间，置顶可拖动
3. 全局快捷键：`Ctrl+Alt+P` 开始/暂停，`Ctrl+Alt+R` 重置（可配置）
4. 主窗口关闭时最小化到托盘而非退出

## 设计要点

- 桌面端独有，`crates/pomodoro-desktop` 扩展，不污染 `crates/pomodoro`
- 托盘库选型：`tray-icon` + `winit` 集成，参考 `gpui` 托盘示例
- 迷你窗：第二个 `WindowOptions` 小尺寸 + `always_on_top`
- GPUI 的全局快捷键需平台 API (Windows `RegisterHotKey` / macOS `CGEventTap`)
