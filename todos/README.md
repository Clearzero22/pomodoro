# todos · 使用说明

每个文件一个可交付任务，包含：目标/需求/设计/拆解/验收。

## 工作流

1. 选一个 `⬜ 待开始` 的任务，把状态改为 `🟡 进行中`
2. 建分支 `feat/00X-xxx`
3. 按「任务拆解」逐项勾选，提交信息带编号 `feat(001): ...`
4. 完成「验收」后改 `✅ 已完成`，提 PR

## 新建任务模板

```md
# 00X · 标题

- **状态**: ⬜ 待开始
- **优先级**: P0/P1/P2
- **分支**: `feat/00X-xxx`
- **依赖**: 001

## 目标
一句话说清

## 需求
1. ...
2. ...

## 设计要点
- ...

## 任务拆解
- [ ] 1. ...

## 验收
- [ ] ...

## 备注
...
```
