# 006 · 主题切换 + 快捷键自定义

- **状态**: ⬜ 待开始
- **优先级**: P1
- **分支**: `feat/006-themes-keybindings`
- **依赖**: 003

## 目标

支持明/暗主题和自定义快捷键。

## 需求

1. 主题：浅色/深色/跟随系统，切换立即生效
2. 快捷键自定义：开始/暂停、重置可改键
3. 设置面板集成

## 设计要点

- 复用 `gpui_kit::Theme`，通过 `Theme::update(cx, |theme| ...)` 切换
- 监听系统主题：`window.appearance()` 变化
- 快捷键配置存 `PomodoroConfig`，变更后 `cx.bind_keys` 重新绑定

## 任务拆解

- [ ] 1. 主题切换逻辑 + 持久化
- [ ] 2. 系统主题跟随
- [ ] 3. 快捷键配置 UI + 冲突检测
- [ ] 4. 持久化 + 热重载

## 验收

- [ ] 切换主题后所有颜色立即更新
- [ ] 跟随系统时改系统主题自动跟随
- [ ] 自定义快捷键重启后保留
